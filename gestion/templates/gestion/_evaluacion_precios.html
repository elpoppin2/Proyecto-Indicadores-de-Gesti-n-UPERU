Cómo se calcula

Precio de cada mes: {% if inf.es_real %}precio real (MB51 + ajustes de la FBL3N){% else %}MB51{% endif %}, el mismo de Precios de entrada. Solo se evalúan los meses con compra. Si el mes de comparación no tuvo compra, se usa el último precio anterior ({{ inf.sustituto }}), marcado con *.{% if inf.desfase == 12 %} La base siempre es un precio del año anterior: si no lo hay hasta ese mes, se usa la primera compra de ese año; un material sin compra el año anterior no se compara (no entra al IPU ni a la bolsa).{% endif %}

Bolsa = (precio del mes − precio base) × {% if inf.unidad_fija %}toneladas{% else %}cantidad{% endif %} del mes evaluado{% if inf.desfase == 12 %}: 2025 vs 2024 con las {% if inf.unidad_fija %}toneladas{% else %}cantidad{% endif %} de 2025, 2026 vs 2025 con las de 2026{% endif %}. La fila Selección pondera todos los materiales: lo pagado ÷ lo que habrían costado esas {% if inf.unidad_fija %}toneladas{% else %}cantidad{% endif %} al precio base.{% if not inf.unidad_fija %} Cada material con su unidad (UND, KG, M…): se compara su precio por unidad consigo mismo, y lo que se suma son soles.{% endif %}

IPU (Índice de Precios Unacem) acumulado del año: {% if inf.desfase == 12 %}de enero al mes T contra el mismo tramo del año anterior, ponderado con las {% if inf.unidad_fija %}toneladas{% else %}cantidad{% endif %} del año más reciente{% else %}variaciones mensuales encadenadas desde enero, (1 + v₁) × (1 + v₂) × … − 1{% endif %}. Se reinicia cada enero.

Si el precio se duplica o cae a menos de la mitad, la comparación se marca con ! (dato atípico): se muestra, pero no suma en la bolsa ni en la selección.
